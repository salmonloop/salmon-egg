# Pinned public surface of SalmonEgg.Acp. One line per exported type:
#
#     <fully-qualified type name> <stable|draft>
#
# The tag is mandatory. A line without one fails to parse, which is the point: a new exported type
# cannot be added without answering whether it belongs to the stable protocol or to the v2 draft,
# and the answer shows up in the diff for review rather than being inferred from a default.
#
#   stable - part of the supported surface. Semver applies; package validation compares it against
#            the last published baseline.
#   draft  - v2 draft surface. Must carry [Experimental(AcpDraftProtocol.DiagnosticId)]; the
#            attribute and this column are asserted to agree in both directions, so marking one
#            without the other is a red gate rather than a silent gap.
#
